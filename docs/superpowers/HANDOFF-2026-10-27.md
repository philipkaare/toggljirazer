# Handoff: 2026-10-27

Everything below is merged into `master` locally (head `98b99c2`). Nothing has been pushed. All 233 tests pass on master.

## What was built

1. **Avalonia port (project 1).** There is now one windowed app for Windows and macOS. The terminal UI and the automatic monthly email are removed. Settings live in `%APPDATA%\ToggJirazer\appsettings.json` (on macOS: `~/Library/Application Support/ToggJirazer/`).
2. **Jira through Atlassian's MCP server (project 2).**
   - The Jira tab has **Sign in with Atlassian** and a site dropdown. The Jira URL, email and API token settings are gone.
   - Before each run the app checks that you are still signed in.
     - In the window, it asks you to sign in again if you aren't.
     - In `--headless`, it exits with code 2.
     - If Atlassian itself is having trouble (5xx errors), it stops the run with a message instead of asking you to sign in.
   - A report is never written with missing Jira data.
3. **Setup wizard (project 3).**
   - It opens on first launch when setup is incomplete, and any time via **Setup…**.
   - It covers:
     - Toggl sign-in with email and password, or a pasted API token. The password is never stored.
     - Toggl organization, workspace and project dropdowns.
     - Atlassian sign-in and site.
     - The Budget and Account fields. A choice of "(none)" is remembered.
     - The report file.
4. **Deferred fixes.**
   - **Sign-in:** it can be cancelled and shows the sign-in link for copying. The port is always released, including when you close the wizard with X during a sign-in.
   - **Jira fields:** the field lookup tries every project before trying more issues in the same one.
   - **Tests and cleanup:** the missing tests are added, tests clean up their temp folders, and the wizard is split into one file per step.

## Decisions Claude made on your behalf

- **Subagents.** Projects 2 and 3 and the fixes were built by subagents, with a reviewer after every task. This cost more tokens but meant every task was checked while you were away.
- **Some tool errors count as signed out.** If a sign-in check fails with an Atlassian tool error that is not server trouble, the app treats you as signed out and offers to sign in again. A failed token refresh can surface that way, and you asked to be prompted.
- **"(none)" stays "(none)".** A saved "(none)" for Budget or Account is kept. The plan had said an empty value falls back to the default name.
- **One task's tests were written after the code.** A reviewer confirmed each of those tests would have failed without the new code.
- **One commit says "Claude Sonnet 5.5"** in its Co-Authored-By trailer, because Sonnet did that task. It was left as is.

## Still open

- **Package warning.** The NU1902/NU1903 security warnings for `System.Security.Cryptography.Pkcs` 10.0.0 are still there. It is pulled in indirectly by MailKit/MimeKit and was not part of the fixes you chose.
- **Port-binding tests.** `AtlassianAuthorizeTests` binds port 33418 on localhost. Those tests fail if a running ToggJirazer is in the middle of signing in.
- **Real Toggl token copied on first launch.** On a first launch with an empty settings folder, the app copies `ToggJirazer/appsettings.development.json` from the build output, which contains your real Toggl token. This is project 1's first-run copy working as designed.
