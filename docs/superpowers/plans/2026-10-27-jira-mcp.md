# Jira MCP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fetch all Jira data through Atlassian's remote MCP server with browser OAuth sign-in. Remove the direct Jira REST code and its URL, email and token settings.

**Architecture:**
- **MCP layer:** `AtlassianMcp` owns the MCP client: OAuth with dynamic client registration, a localhost callback, and a DPAPI-protected file token cache. It exposes an `IJiraTools` abstraction that unwraps tool results into `JsonElement`.
- **`JiraService`:** keeps its public API but is re-implemented on `IJiraTools` using batched JQL.
- **Cache:** a tool-level cache replaces the HTTP cache for Jira.
- **Sign-in UI:** a reusable `AtlassianSignInControl` provides sign-in, status and the site dropdown.
- **Run check:** each run checks the sign-in before starting. The GUI prompts the user to sign in again. Headless exits with code 2.

**Tech Stack:** .NET 10, Avalonia 11.3.22, ModelContextProtocol.Core 2.x (newest stable, 2.3.0 at plan time), System.Security.Cryptography.ProtectedData, xUnit, Avalonia.Headless.XUnit.

**Spec:** `docs/superpowers/specs/2026-10-27-jira-mcp-design.md`. Read it: its "Facts established" and "Builder-check calls" sections pin the tool names, argument names, response shapes and error handling.

## Global Constraints

- **No network calls in tests.** Use only canned JSON in the exact shapes from the spec, with synthetic keys like `ABC-1` and no real site data.
- **Never launch the app or `--headless` against the real per-user settings.** Every app launch sets `TOGGJIRAZER_SETTINGS_DIR` to a fresh temp folder.
- **Build output:** build and test with `--artifacts-path <scratch dir>`, because Philip's running app may lock `bin/`.
- **MCP endpoint:** `https://mcp.atlassian.com/v2/mcp`. Redirect URI: `http://localhost:33418/callback`.
- **Token file:** `atlassian-auth.json` in the per-user settings folder. DPAPI CurrentUser on Windows, mode 600 on macOS, written atomically (temp file plus rename).
- **No browser outside an explicit sign-in:** the browser only opens during an explicit sign-in, never in headless mode or during the startup status check.
- **Exact strings:**
  - `Not signed in to Atlassian. Open ToggJirazer and use 'Sign in with Atlassian' on the Jira tab.` (headless; exit code 2)
  - `Your Atlassian sign-in has expired. Sign in again?` (GUI prompt; buttons **Sign in** and **Cancel**)
  - `Pick your Atlassian site (Jira tab).` (validators)
  - `Atlassian rate limit reached — try again later (the 1-day cache keeps what was fetched).`
  - `Sign-in was cancelled or timed out.`
- **Report output unchanged.** Every existing test stays green.
- **Commits:** messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **A JQL chunk with a nonexistent or invisible key.** The remaining keys must still be fetched, the missing key reported as today, and the loop must always make progress (no infinite retry). Tested in Task 2 (`Bulk_retries_chunk_without_missing_keys`, `Bulk_halving_terminates_when_error_text_unparseable`).
2. **An issue with several fix versions, all in the batched `fixVersion in (...)` query.** It must count toward each version, exactly as per-version queries did. Tested in Task 2 (`Batched_version_grouping_equals_per_version`).
3. **A sign-in that expires mid-run, or a 429.** The run stops and never writes a report with partial Jira data. Tested in Task 2 (`Auth_error_mid_run_throws`, `Rate_limit_throws_with_message`).
4. **A legacy settings file with `BaseUrl`, `UserEmail` and `ApiToken`.** It loads with `SiteUrl` set, and the first Save drops the old token. Tested in Task 3 (`Legacy_jira_baseurl_migrates_to_siteurl`, `Save_drops_legacy_jira_credentials`).
5. **A corrupt or undecryptable `atlassian-auth.json`.** It is treated as "not signed in" and never crashes startup. Tested in Task 1 (`TokenStore_corrupt_file_reads_as_null`).

```csharp
public interface IJiraTools
{
    // Calls an Atlassian MCP tool and returns the parsed JSON payload (the text content parsed as JSON).
    // Throws AtlassianAuthException, AtlassianRateLimitException, or AtlassianToolException(message, statusCode).
    Task<JsonElement> CallToolAsync(string toolName, IReadOnlyDictionary<string, object?> arguments, CancellationToken ct = default);
}
public sealed class AtlassianAuthException(string message, Exception? inner = null) : Exception(message, inner);
public sealed class AtlassianRateLimitException() : Exception("Atlassian rate limit reached — try again later (the 1-day cache keeps what was fetched).");
public sealed class AtlassianToolException(string message, int? statusCode) : Exception(message) { public int? StatusCode { get; } = statusCode; }

public static class AtlassianToolResult
{
    // Parses tool text content. isError/error payloads like {"error":true,"message":...,"statusCode":400,"rateLimit":{"remaining":N}}
    // map to: 401/403 → AtlassianAuthException; 429 or rateLimit.remaining==0 → AtlassianRateLimitException; else AtlassianToolException.
    public static JsonElement Parse(string text, bool isError);
}

public sealed record AtlassianSite(string CloudId, string Url, string Name);

public sealed class AtlassianTokenStore : ModelContextProtocol.Authentication.ITokenCache
{
    public AtlassianTokenStore(string filePath);           // e.g. <settings dir>/atlassian-auth.json
    public bool HasTokens { get; }                          // file exists and decrypts to a token container
    public void Clear();                                    // sign out: delete the file
    public (string ClientId, string? ClientSecret)? ClientRegistration { get; set; } // persisted alongside tokens
    // ITokenCache.GetTokensAsync re-reads the file every call; StoreTokensAsync writes atomically.
}

public sealed class OAuthCallbackListener
{
    public static readonly Uri RedirectUri = new("http://localhost:33418/callback");
    // Listens once on RedirectUri, serves "Signed in — you can close this tab.", returns code/state/iss.
    public Task<(string Code, string? State, string? Iss)> WaitForCallbackAsync(TimeSpan timeout, CancellationToken ct);
    public static (string Code, string? State, string? Iss) ParseQuery(string query); // throws AtlassianAuthException on error= or missing code
}

public sealed class AtlassianMcp : IAsyncDisposable
{
    public AtlassianMcp(AtlassianTokenStore store, Action<Uri> openBrowser);
    public Task SignInAsync(CancellationToken ct);                     // explicit interactive sign-in (only place a browser opens)
    public Task<IReadOnlyList<AtlassianSite>> GetSitesAsync(CancellationToken ct); // getAccessibleAtlassianResources, deduped by id; throws AtlassianAuthException when not signed in
    public Task<bool> IsSignedInAsync(CancellationToken ct);           // false on AtlassianAuthException or !store.HasTokens; never opens a browser
    public IJiraTools Tools { get; }                                   // non-interactive client
}

public sealed class ToolResultCache
{
    public ToolResultCache(string directory, TimeSpan expiration, Func<Exception, bool>? onWritePermissionError = null);
    public IJiraTools Wrap(IJiraTools inner);   // key = SHA256(toolName + canonical sorted-key JSON of args); stores raw JSON text
}
```
